المعهد العالي للهندسة والعلوم الإدارية - دليل الرفع على السيرفر
========================================

المحتويات:
- index.html : الموقع الجاهز للرفع مباشرة (Single File - يعمل بدون أي إعدادات)
- src/ : ملفات المصدر الأصلية (App.tsx + index.css) للتعديل المستقبلي
- package.json + vite.config.js + tailwind.config.js : لتطوير المشروع كـ React
- .htaccess : لاستضافة Apache / cPanel

طريقة الرفع السريع (موصى بها):
1. ادخل cPanel > File Manager > public_html
2. ارفع ملف index.html فقط
3. افتح موقعك: www.yourdomain.com
الموقع سيعمل فوراً لأنه ملف واحد يحتوي كل شيء (CSS + JS).

طريقة الرفع الكاملة (للمطورين):
1. npm install
2. npm run build
3. ارفع محتويات مجلد dist إلى public_html

المميزات المضمنة:
- رؤية المعهد وتطلعاته
- شرح المواد + اختبارات تفاعلية حقيقية (JavaScript)
- هيئة التدريس
- المعامل والمختبرات
- التدريب العملي
- نموذج شئون الطلاب (شكاوى ومقترحات)

للدعم: عدل ملف src/App.tsx ثم أعد البناء.
